# AI Usage Report

During PPL, our use of Generative AI tools (such as ChatGPT, Gemini, and Copilot) remained focused on supporting development and maintaining project documentation. However, compared to previous sprints, the amount of active development was lower, so AI usage was more moderate and centered mainly around maintenance, small improvements, and workflow support.

## 1. Supporting Maintenance & Minor Improvements

As this stage involved fewer new features and less intensive development work, AI tools were mainly used to assist with smaller adjustments and maintenance tasks across the project.

- **Code Refinement:** AI was occasionally used to suggest cleaner implementations and small optimizations in both frontend and backend code.

- **Bug Fixing Support:** We used AI to help identify possible causes of minor issues and validate potential fixes before implementation.

- **Improving Existing Features:** AI assisted in refining already implemented functionalities, helping ensure stable behavior and smoother user interactions.

## 2. Documentation Updates

Although development activity was lighter during this sprint, keeping the documentation aligned with the current state of the project remained important.

- **Updating Documentation:** AI helped revise existing documentation to reflect the latest project structure, implemented features, and adjustments made during the sprint.

- **Improving Clarity:** AI tools were used to reorganize and simplify technical explanations, making documentation easier to read and maintain.

## 3. Workflow & Team Assistance

AI tools also continued to support the team’s general workflow and collaboration processes.

- **Pull Request Support:** AI was occasionally used to help structure pull request descriptions and summarize changes more clearly.

- **Reducing Repetitive Work:** AI assisted with repetitive or low-complexity tasks, allowing the team to focus on coordination, testing, and polishing existing functionalities.

- **Validation & Review Assistance:** Before closing tasks, AI was sometimes used as a secondary review tool to suggest missing validations or possible edge cases.
