# AI Usage Report

Throughout Sprint 3, our team continued to leverage Generative AI tools (such as ChatGPT, Gemini, and Copilot) to support development, improve code quality, and maintain clear and consistent documentation. Compared to previous sprints, our use of AI remained similar, mainly focused on assisting development tasks.

### 1. Accelerating Advanced Development & Testing
Con la arquitectura fundamental establecida en el Sprint 2, abordamos funcionalidades más complejas en este sprint. Utilizamos la IA como herramienta de programación en pareja para agilizar las tareas de codificación repetitivas y optimizar nuestra lógica.

* **Refactoring and Optimization:** We used AI to suggest cleaner and more maintainable implementations in both React Native components and Spring Boot services.

- **Feature Adjustments:** AI helped us refine existing functionalities, such as handling user interactions, improving UI behavior, and ensuring correct data flow between frontend and backend.
- **Generating Boilerplate Code:** For some repetitive structures, AI was used to speed up initial code generation, which was later reviewed and adapted by the team.

### 2. Maintaining & Updating Documentation
As the app's functionality grew, keeping the documentation up to date became crucial. We relied on AI to ensure our technical writing remained accurate and accessible.

- **Writing and Structuring Documentation:** AI was used to draft and organize documentation, ensuring it was clear and easy to understand.

- **Updating Existing Content:** We used AI to revise and adapt documentation from previous sprints to reflect the current state of the project.

## 3. Workflow and Code Review Assistance

AI tools were also used to support the team's workflow and collaboration.

- **Pull Request Descriptions:** AI was occasionally used to help write clearer and more structured PR descriptions.

- **Development Efficiency:** AI helped reduce time spent on repetitive tasks, allowing the team to focus on more relevant aspects of development.

* **Spotting Edge Cases:** Before finalizing a feature, we would prompt the AI to suggest potential edge cases or missing validations, acting as a "second set of eyes" to strengthen our logic.
